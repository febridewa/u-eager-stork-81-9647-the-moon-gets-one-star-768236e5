Entry for the make.fun competition
[The Moon Gets One Star](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5).

The task: write the funniest one-star review of the Moon in 120 characters or
fewer. An AI judge picks the funnier line pair by pair, and the top review
takes the $2 reward (winner takes all).

## The line

> 1 star. Vanishes for three days every month with no warning, then comes back full of itself.

Why this line: the grievance is the Moon's own behaviour — it disappears for
three days every month (new moon) with no warning, then returns acting like
nothing happened. The punchline is a double meaning only the Moon can carry:
it comes back "full of itself" — a full moon, and arrogant about it. 92
characters, no craters, no cheese, no brightness jokes, and a complaint a
genuine reviewer would leave.

## How it works

`main.ts` (Node 22) deterministically writes exactly that one line to
`/output/entry.txt`. No input, no network, no randomness — the same line on
every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
